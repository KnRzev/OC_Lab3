# Лабораторная работа №3 — вариант 6

**Тема:** Межпроцессное взаимодействие через именованную разделяемую память (`shm_open`, `mmap`) и именованные семафоры.

**Условие:** Родительская программа запрашивает имя файла и открывает его для чтения. Файл подключается к стандартному вводу дочерней программы. В нём записаны строки с произвольным количеством целых чисел типа `int`. Дочерняя программа вычисляет сумму чисел каждой строки и передаёт результаты родителю через разделяемую память. Родитель выводит суммы в терминал. Доступ к общей памяти согласуется семафорами. Родитель и ребёнок — отдельные программы.

## Компиляция и запуск (Linux)

Все команды выполняются из папки проекта `OC_Lab3`. Файлы `parent`, `child` и `numbers.txt` находятся в этой же папке.

```bash
gcc -std=c11 -Wall -Wextra parent.c -o parent -pthread -lrt
gcc -std=c11 -Wall -Wextra child.c -o child -pthread -lrt
./parent
```

После запуска введите имя файла, например `numbers.txt`. Имя вводится без пробелов.

## Пример

Содержимое `numbers.txt`:

```text
10 20 30
5 15 25
100 200 300
-10 5 3
2147483647 1
```

Результат:

```text
60
45
600
-2
2147483648
```

Входные числа имеют тип `int`, а сумма накапливается в `long long`.
